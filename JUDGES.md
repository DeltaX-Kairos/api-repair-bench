# Judge path

1. Open the [live workspace](https://repairbench.deltaxevaluate.com/live/).
2. Choose **Invoice repair** and click **Run live repair** once.
3. Watch **NVIDIA Nemotron** propose a patch through **Nebius Token Factory**.
4. Watch **Nebius Sandbox** run the nine checks. A fresh proposal may pass immediately or expose a failed check.
5. Inspect the generated function, the optional single correction, the stopping reason and **Download evidence**.

If the live allowance is used, open the [saved replay](https://repairbench.deltaxevaluate.com/) and select the recorded invoice repair. The live run is one observed demonstration, not a reliability guarantee, and generated code is never deployed automatically.

## Enforced controls

Model output has proposal authority only. Application code enforces artifact binding, remote dispatch, result eligibility and a finite correction protocol. Candidate execution is remote; final comparison is external. The observation runner still shares the candidate process, so passing checks do not establish independently attested execution.
